# Contribution Guidelines

Thank you for wanting to contribute to **Awesome Codex Themes**! 🎨

## Adding a theme or resource

Please ensure your pull request adheres to the following guidelines:

- The entry is related to theming/skinning **OpenAI Codex** (the Codex CLI, IDE extension, or desktop app). Unrelated projects that happen to be named "Codex" will not be accepted.
- Search previous suggestions before making a new one to avoid duplicates.
- Make an individual pull request for each suggestion.
- Use the following format: `[Name](link) — Description.`
- Descriptions should be short, simple, and end with a period.
- Keep entries in alphabetical order within each section, unless the section is ordered otherwise (e.g. by popularity).
- New categories or improvements to the existing categorization are welcome.
- Check your spelling and grammar.
- For a theme entry, a screenshot/preview link is strongly encouraged.

## For CLI theme submissions

- Custom Codex CLI themes are standard TextMate `.tmTheme` files placed in `$CODEX_HOME/themes/`. Please link to the raw `.tmTheme` file or a repo containing it.
- Mention whether the theme is dark, light, or both.

Thank you for your suggestions!
