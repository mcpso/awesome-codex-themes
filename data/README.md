# Research Data

This directory contains structured source data used by the curated list.

## `x-posts.json`

Public X posts about Codex themes, skins, theme tools, and notable theming
moments. Each record contains:

- the canonical X post URL and post ID;
- author name and handle;
- publication date and language;
- a short editorial summary;
- the kind of resource being shown;
- related projects already listed in the main README, when known;
- how and when the post metadata was verified.

Post text is summarized rather than mirrored in full. Engagement counts are not
stored because they change continuously. Entries are checked against X's public
oEmbed response before being added.
